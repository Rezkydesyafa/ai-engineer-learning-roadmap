# AI Engineer Roadmap

## Phase 1 — Engineering Foundations

- [ ] Foundations: Linux, CLI, Git, Python, mathematics, statistics, SQL
- [ ] Software engineering: clean code, testing, REST APIs, FastAPI, Docker, system design
- [ ] Data engineering: NumPy, pandas, cleaning, pipelines, vector databases

## Phase 2 — Machine Learning

- [ ] Machine learning fundamentals
- [ ] Supervised and unsupervised learning
- [ ] Feature engineering and model evaluation
- [ ] End-to-end machine learning project
- [ ] Deep learning with PyTorch
- [ ] CNN, RNN/LSTM, and transformers

## Phase 3 — LLM Engineering

- [ ] Tokenization and transformer architecture
- [ ] Prompt engineering and structured output
- [ ] Function/tool calling and open-source LLMs
- [ ] Embeddings, chunking, and vector search
- [ ] Basic, advanced, evaluated, and production RAG
- [ ] Agent fundamentals, tools, memory, MCP, and multi-agent systems

## Phase 4 — Optimization and Evaluation

- [ ] Dataset preparation and supervised fine-tuning
- [ ] LoRA and QLoRA
- [ ] LLM, RAG, and agent evaluation
- [ ] LLM-as-judge and observability

## Phase 5 — Production AI

- [ ] Model serving and FastAPI
- [ ] Docker and CI/CD
- [ ] Monitoring and cloud deployment
- [ ] Prompt-injection defense, privacy, guardrails, and responsible AI
